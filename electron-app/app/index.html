Tape Art
Where to download tape art images:
Visit tapeartrepros.sergiostuff.com — a library of high-resolution cassette J-card reproductions. Download the images you want, then save them into a dedicated folder on your computer (e.g. tape-art/).
File naming tip: name each file after the cassette type so the app can label it automatically, e.g. TDK-SA-X-C90.jpg, Maxell-XLII-90-1985.jpg, Sony-Metal-C60.jpg.

Select all the image files from your tape-art/ folder. The cassette type label is derived from the file name automatically.
